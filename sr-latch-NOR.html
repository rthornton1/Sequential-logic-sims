SR Latch Simulator

Two cross-coupled NOR gates with no clock. Click S or R, and the outputs change right away.

S stands for Set: making S = 1 sets the output to Q = 1. R stands for Reset: making R = 1 resets the output to Q = 0.

The highlighted row matches the current inputs. Q = NOR(R, Q̅) and Q̅ = NOR(S, Q).

Things to try

1. With R = 0, set S = 1, then S = 0. Q stays 1. This is the 1-bit memory.
2. With S = 0, set R = 1, then R = 0. Q stays 0. This is the 1-bit memory.
3. Set S = R = 1. Q and Q̅ are both 0, so Q̅ is no longer the complement of Q.
4. From S = R = 1, click "Set both S and R to 0." The final state is unpredictable (a race condition).
