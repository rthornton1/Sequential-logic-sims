NAND SR Latch Simulator

Two cross-coupled NAND gates with no clock. Click S̅ or R̅, and the outputs change right away.

The inputs are active-low: the bar means an input acts when it is 0. S̅ stands for Set: making S̅ = 0 sets the output to Q = 1. R̅ stands for Reset: making R̅ = 0 resets the output to Q = 0.

Things to try

1. Set S̅ = 0, then S̅ = 1. Q stays 1. This is the 1-bit memory.
2. Set R̅ = 0, then R̅ = 1. Q stays 0. This is the 1-bit memory.
3. Set S̅ = R̅ = 0. Q and Q̅ are both 1, so Q̅ is no longer the complement of Q.
4. From S̅ = R̅ = 0, click "Set both S̅ and R̅ to 1." The final state is unpredictable (a race condition).
