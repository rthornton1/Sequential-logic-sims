T Flip-Flop Simulator

T stands for Toggle. Q can change only at the active clock edge, which you can set to rising (0 → 1) or falling (1 → 0). T = 1 toggles Q, and T = 0 holds it.

Things to try

1. Set T = 0. Q holds.
2. Set T = 1. Q toggles at every active edge.
3. With T = 1, compare Q and CLK on the timing diagram. Q completes one cycle for every two clock cycles, so its frequency is half the clock's.
4. Switch to "Falling edge." Q now toggles when CLK goes from 1 to 0, and a bubble appears on the clock input of the symbol.
