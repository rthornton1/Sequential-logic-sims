D Latch vs. D Flip-Flop

The same D and clock drive both parts. The D latch is level-triggered: while CLK = 1, Q follows D. The D flip-flop is edge-triggered: Q takes the value of D only at the rising edge, when CLK goes from 0 to 1.

Things to try

1. While CLK = 1, click D a few times. The latch's Q follows every change, but the flip-flop's Q doesn't change.
2. While CLK = 0, click D. Neither Q changes.
3. Watch the dashed lines. The flip-flop's Q changes only there, taking the value D has at that instant.
4. Click "Pause clock" to freeze the timing diagram so you can study it.
